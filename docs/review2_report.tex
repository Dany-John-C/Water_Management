\section{Objective}

To design and implement an AI-powered IoT water management system that uses \textbf{multi-sensor probabilistic fusion} to detect, localize, and respond to water leaks and anomalies in real-time.

The system uses a 2-tier edge architecture (Arduino Uno R3 + NodeMCU ESP8266) with four sensors (Resistive Water Level Sensor, YF-S201, YL-69, DS18B20) and runs 10 AI/ML engines — including Bayesian leak detection, weather-adaptive irrigation, physics-based sensor self-diagnostics, adaptive energy optimization, and online baseline learning — all implemented from scratch in pure Python.

Key objectives:
\begin{itemize}
    \item Detect leaks via multi-sensor fusion: $P(\text{leak}) = 1 - \prod_{i=1}^{n}(1 - P_i)$
    \item Auto-close servo valves on leak detection and verify stoppage
    \item Self-diagnose sensor faults using physics cross-validation
    \item Optimize energy by adapting sampling (2s--60s) based on stability index
    \item Learn installation-specific baselines via Welford's online algorithm
    \item Visualize on a real-time 3D web dashboard (Three.js + Chart.js)
\end{itemize}
